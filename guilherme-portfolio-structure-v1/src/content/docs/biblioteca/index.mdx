# Biblioteca técnica

Esta é a área principal para organizar conteúdos longos do portfólio: projetos, estudos, anotações, fotos, vídeos, histórias, documentos, bastidores e aprendizados.

A ideia é que cada página tenha espaço para três camadas:

1. **Resumo rápido** para recrutadores entenderem o valor do projeto.
2. **História completa** para contar contexto, decisões, erros, testes e aprendizados.
3. **Mídias e evidências** para fotos, vídeos, diagramas, prints, código e documentos.

## Áreas iniciais

- **Projetos:** Biometria Neonatal, Pato a Jato, Robotnik e outros projetos práticos.
- **IA Embarcada:** TCC, ONNX Runtime, visão computacional, desempenho e Raspberry Pi.
- **Segurança da Informação:** Cisco, fundamentos, automações, Linux e SOC.
- **Templates:** modelos prontos para você criar novas páginas sem começar do zero.

## Como adicionar uma página nova

Crie um arquivo `.mdx` dentro de `src/content/docs/biblioteca/alguma-area/`.

Use o modelo em **Templates → Modelo de página** para manter tudo padronizado.
