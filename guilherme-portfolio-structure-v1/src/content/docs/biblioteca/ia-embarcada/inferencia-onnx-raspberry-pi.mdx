# Inferência ONNX em Raspberry Pi

Página para reunir anotações técnicas sobre execução de modelos de machine learning em Raspberry Pi, usando ONNX Runtime, OpenCV, Linux e medições de desempenho.

## Ideias para preencher

- Setup de hardware e sistema operacional.
- Instalação de dependências.
- Diferença entre Python e C++.
- Métricas coletadas: tempo de inferência, FPS, CPU, RAM e latência.
- Dificuldades encontradas.
- Resultados e próximos passos.
