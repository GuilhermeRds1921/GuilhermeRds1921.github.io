# Biometria Neonatal e IA Embarcada

<TechBadges items={["Machine Learning", "Visão Computacional", "Raspberry Pi", "ONNX Runtime", "OpenCV", "Linux"]} />

## Resumo rápido

Projeto de pesquisa na UTFPR-PB envolvendo biometria neonatal, visão computacional, machine learning e processamento de imagens. Meu TCC segue essa linha, avaliando a execução de modelos de redes neurais em plataformas embarcadas, com foco em desempenho, limitações e viabilidade prática.

<StoryCallout title="Ideia central">
O objetivo é entender como levar modelos de inteligência artificial para dispositivos embarcados, como Raspberry Pi, reduzindo a dependência de um computador convencional.
</StoryCallout>

## História do projeto

Use esta seção para contar a trajetória: como entrou no grupo, qual problema o projeto busca resolver, quais limitações existiam no sistema, quais testes foram feitos e como o TCC se encaixou nisso.

## O que eu fiz

- Avaliação de execução de modelos de machine learning em plataformas embarcadas.
- Testes com Python, C++, OpenCV, ONNX Runtime e Linux.
- Medição de desempenho, limitações e viabilidade de aplicação prática.
- Estudos sobre integração entre IA, software e hardware.

## Aprendizados

- Diferença entre executar IA em PC e em plataforma embarcada.
- Importância de desempenho, consumo de recursos, latência e reprodutibilidade.
- Como pesquisa aplicada pode virar uma solução mais próxima de uso real.
