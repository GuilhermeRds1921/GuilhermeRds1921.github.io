# Guilherme Rodrigues — Portfolio Starter

Portfólio e biblioteca técnica em **Astro + Starlight**, preparado para GitHub Pages.

## Rodar localmente

```bash
npm install
npm run dev
```

## Estrutura

- `src/pages/index.astro`: página inicial estilo acadêmico/profissional.
- `src/content/docs/biblioteca/`: biblioteca em Markdown/MDX com sidebar.
- `src/components/`: componentes para galerias, vídeos, histórias e tecnologias.
- `public/images/`: imagens públicas do portfólio.
- `.github/workflows/deploy.yml`: deploy no GitHub Pages.

## Ideia visual

A home segue uma linha acadêmica/profissional: hero com nome, navegação por seções, About, Facts, Resume, Projects, Skills, Library e Contact. A biblioteca continua organizada como documentação para textos longos, fotos, vídeos e anotações técnicas.
